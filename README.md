# Interactive Flight Experience

Interactive WebGL flight demo built with Nuxt 4, TresJS (Three.js + Vue), and custom GLSL shaders.

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

Opens on `http://localhost:3000`.

## Linting

```bash
pnpm lint         # ESLint + Stylelint
pnpm lint:js
pnpm lint:style
```
